# KMHS Beta Club - Member Portal

Built for the National Beta Club chapter I founded at Kennesaw Mountain High School. The national portal only tracked dues - built ours from scratch to actually run a chapter.

## What it does
- Service hour logging - verified by leadership, counts toward graduation requirements
- Member account management
- Event tracking and announcements
- Dues tracking
- Bylaws and chapter info

## Tech Stack
- Next.js, React, TypeScript, Tailwind CSS
- Firebase (Auth, Firestore, Hosting)
- Google Cloud Platform, Cloudflare

## Background
Founded KMHS's Beta Club chapter sophomore year. The national Beta portal was basically useless for day-to-day operations so I built a full replacement. School still uses paper forms for non-club hours - this replaced that entirely for our chapter.

## Running locally
```bash
npm install
npm run dev
```
