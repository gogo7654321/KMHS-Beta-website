# **App Name**: BetaSphere KMHS

## Core Features:

- Dynamic Event Calendar: Displays upcoming Beta Club events in a visually appealing card format, allowing users to filter by event type. Event details include date, time, location, description, and RSVP status.
- Service Hour Tracker: Implements a visual progress bar to show the chapter's total service hours goal, along with a leaderboard of top volunteers and charts illustrating service impact over time.
- AI-Powered Event Suggestion Tool: Uses an AI model to suggest event ideas based on trending community needs and member interests, improving the chapter's engagement and service relevance. The model will use reasoning to decide which event types are most appropriate to suggest to users based on community needs. Includes tool to suggest events.
- Leadership Showcase: Presents the Beta Club's leadership team in a grid layout, with photos, names, positions, grades, bios, and contact information displayed on hover.
- Interactive Photo Gallery: Organizes photos from Beta Club activities into a masonry grid layout, categorized by event type. Implements a lightbox viewer for detailed photo viewing.
- Membership Benefits Overview: Highlights membership benefits using an icon-based layout, promoting opportunities like scholarships, leadership roles, community service, and networking.
- Admin Portal: The website contains a restricted section where the administration of the Beta Club can create new announcements.

## Style Guidelines:

- Primary color: Navy blue (#003366) to reflect the National Beta Club colors and provide a sense of trust and stability.
- Background color: Light blue (#D9E2EF) for a calm and professional look, derived from the navy blue hue with low saturation.
- Accent color: Gold (#B8860B) to highlight key elements and CTAs, analogous to navy blue for visual harmony but different in brightness and saturation for contrast.
- Headers: 'Poppins' (sans-serif) for a geometric, contemporary feel; to ensure legibility on headers, its boldness/weight can be tuned on a case by case basis; the 'PT Sans' is too similar and a more professional font that differentiates more between headers and body should be used instead.
- Body: 'Inter' (sans-serif) for a clean and readable style, providing excellent readability and a modern look. 'Inter' can also be used for headers; this way the number of fonts used can be reduced to one.
- Use flat design icons with rounded edges, in gold and navy blue, to represent different sections and features. The style needs to be coherent with the rest of the design.
- Employ a grid-based layout with clear sections and whitespace to ensure readability and ease of navigation. Make sure it is mobile-responsive.
- Incorporate subtle animations, such as fade-in effects, hover animations, and smooth scrolling, to enhance user experience and engagement. The 'Framer Motion' is the perfect package for it.
